## 🚀 Как использовать новые функции

### 1. Доступ к админ-панели

```bash
# 1. Установите пароль
export ADMIN_PASSWORD="секретный_пароль"

# 2. Запустите систему
python main.py

# 3. Откройте браузер
http://localhost:3000/admin/panel

# 4. Войдите с паролем
```

### 2. Управление каналами

**Добавить канал:**
1. Войдите в админ-панель
2. Введите `@channel_name` или ID
3. Нажмите "+ Добавить"
4. Перезапустите сервер

**Удалить канал:**
1. Найдите в списке
2. Нажмите "Удалить"
3. Перезапустите сервер

### 3. Просмотр карты

Карта теперь:
- ✅ Светлая и читаемая
- ✅ С границами Украины (зелёный контур)
- ✅ Крым обозначен как украинская территория

## 🎯 Что нужно сделать на Render

### 1. Добавьте новые переменные

В Environment Variables:

```
ADMIN_PASSWORD = ваш_секретный_пароль
SECRET_KEY = случайная_длинная_строка
```

### 2. Передеплойте

Manual Deploy → Clear build cache & deploy

### 3. Проверьте

1. Откройте карту - должна быть светлая с границами
2. Откройте `/admin/panel` - должна быть админ-панель
3. Войдите с паролем
4. Добавьте тестовый канал
