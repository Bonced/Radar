# 🔐 ИНСТРУКЦИЯ ПО АДМИН-ПАНЕЛИ

## Что такое админ-панель?

**Админ-панель** — это защищённый паролем интерфейс для управления userbot без изменения кода или переменных окружения.

### Возможности:

✅ Добавлять/удалять каналы для мониторинга  
✅ Просматривать статус userbot  
✅ Смотреть статистику угроз  
✅ Управлять без перезапуска кода

---

## 🚀 Быстрый старт

### 1. Установите пароль администратора

**На Render.com:**
1. Зайдите в Environment Variables
2. Добавьте переменную:
   ```
   ADMIN_PASSWORD = ваш_секретный_пароль
   ```
3. Сохраните и передеплойте

**Локально:**
```bash
export ADMIN_PASSWORD="ваш_пароль"
```

Если не установить — пароль по умолчанию: `admin123`

### 2. Откройте админ-панель

```
https://ваш-сайт.onrender.com/admin/panel
```

Или локально:
```
http://localhost:3000/admin/panel
```

### 3. Войдите

Введите пароль из шага 1

---

## 📋 Как пользоваться

### Добавить канал для мониторинга

1. Откройте админ-панель
2. В разделе "КАНАЛЫ ДЛЯ МОНИТОРИНГА"
3. В поле введите:
   - `@channel_username` (для каналов с username)
   - `-1001234567890` (для каналов без username - ID)
4. Нажмите "+ Добавить"
5. **Перезапустите сервер** для применения изменений

### Удалить канал

1. Найдите канал в списке
2. Нажмите "Удалить" справа
3. Подтвердите удаление
4. **Перезапустите сервер**

### Посмотреть статус

В панели видно:
- **Статус userbot** - запущен или остановлен
- **Активных каналов** - сколько каналов мониторится
- **Всего угроз** - сколько угроз в базе данных
- **Активных угроз** - угрозы за последний час

## 🔍 Как узнать ID канала?

### Способ 1: Через userbot.py

```bash
python userbot.py --auth
```

Скрипт покажет все ваши каналы с ID

### Способ 2: Через веб-версию Telegram

1. Откройте канал в web.telegram.org
2. URL будет выглядеть как: `web.telegram.org/k/#-1001234567890`
3. Число после `#` — это ID канала

### Способ 3: Через бота @getidsbot

1. Добавьте бота @getidsbot в канал
2. Переслайте любое сообщение из канала боту
3. Бот покажет ID

## ⚙️ Настройки безопасности

### Измените пароль по умолчанию!

**ВАЖНО:** Пароль по умолчанию `admin123` небезопасен!

Установите сложный пароль:
```bash
export ADMIN_PASSWORD="мой_сложный_пароль_2024!"
```

### Рекомендации:

- ✅ Используйте длинный пароль (12+ символов)
- ✅ Комбинируйте буквы, цифры, символы
- ✅ Не используйте простые слова
- ❌ Не храните пароль в коде
- ❌ Не коммитьте пароль в Git

## 🔄 Применение изменений

После добавления/удаления каналов нужно **перезапустить сервер**:

### На Render.com:

1. Зайдите в ваш сервис
2. Нажмите "Manual Deploy" → "Clear build cache & deploy"
3. Или просто: Settings → "Restart"

### Локально:

```bash
# Остановите (Ctrl+C)
# Запустите снова
python main.py
```

## 🆘 Решение проблем

### "Неверный пароль"
**Проблема:** Не могу войти  
**Решение:** Проверьте `ADMIN_PASSWORD` в Environment Variables

### Изменения не применяются
**Проблема:** Добавил канал, но userbot его не видит  
**Решение:** Перезапустите сервер (Manual Deploy на Render)

### "Канал already exists"
**Проблема:** Не могу добавить канал  
**Решение:** Канал уже есть в списке, проверьте написание

### Забыл пароль
**Решение:**  
1. Зайдите в Render → Environment Variables
2. Измените `ADMIN_PASSWORD` на новый
3. Перезапустите сервер

## 💡 Полезные советы

### 1. Автоматическое обновление каналов

Можете создать список каналов в файле `monitored_channels.json` - админ-панель его использует

### 2. Мониторинг всех каналов

Если список каналов **пустой** — userbot мониторит **ВСЕ** каналы и чаты

### 3. Фильтрация по источникам

Добавляйте только проверенные источники для точности данных

### 4. Проверка логов

Смотрите логи на Render чтобы видеть какие сообщения парсятся:
```
✅ Новая угроза: DRONE → Kharkiv [Alert Channel]
```
